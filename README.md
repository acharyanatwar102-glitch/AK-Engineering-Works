# AK Engineering Works — Demo Website Template

A responsive, self-contained HTML5/CSS3/JavaScript starter website for **AK Engineering Works**.

## Folder Structure
- `index.html` — Main single-page layout (Hero, About, Services, Filterable Projects, Contact/RFQ Form)
- `css/style.css` — Responsive industrial styling (slate navy & safety orange palette)
- `js/main.js` — Mobile menu toggle, project category filtering, and interactive RFQ form feedback

## How to Run
Open `index.html` directly in any web browser, or serve the folder using VS Code Live Server or `python -m http.server`.
